## The mux workstream (the design in one paragraph)

The fork already ships ~80% of the substrate for a ghostty-native agent
mux in `src/apprt/ipc/`: a 1300+ line Zig implementation of the
"Khostty Agent IPC Protocol (v1)" — `protocol.zig`, `auth.zig`,
`state.zig`, `events.zig`, `pane.zig`, `handler.zig`, `server.zig`,
`fake_host.zig` (the test backend), and `app_host.zig` (the real
runtime `Host` impl that had never been wired into the build graph).

**Phase 0 (DONE on this session's branch):** wire `app_host.zig` into
the Zig build graph for the first time. One new build step
(`test-agent-ipc`), one new test root (`src/main_agent_ipc.zig`), a
small cleanup in `app_host.zig`. Zero runtime-behavior changes —
exercises `app_host.zig` over `fake_host.zig` underneath, same as the
other `src/apprt/ipc/*.zig` tests.

**Phase 1 (NOT STARTED):** mux shell binary reusing `protocol.zig` /
`auth.zig`. Blocked on GTK runtime (operator is on macOS, GTK runtime
not on the host). Local-only mock prototype is doable; real GTK

**Future phases:** deferred. See `00_SESSION_OVERVIEW.md` for the
full design brief, `01_PHASE0_RESULTS.md` for the Phase 0 results,
