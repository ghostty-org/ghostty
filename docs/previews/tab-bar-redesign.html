Tabs and split panes

Capsule tabs with even spacing, in four positions: top (titlebar), bottom, left sidebar or right sidebar. Everything is set from a Tab Bar settings window, and changes show up live in every open window. You don't edit the config file.

Spec

Default values. All of them except padding can be changed in the settings window.

Capsule height28ptRadius = height ÷ 2 at 100% roundness
Spacing6ptSame between tabs and before the + button
Bar padding8 / 12ptVertical / horizontal, so tabs sit centered in the bar
Tab width84–200ptFit title; titles truncate in the middle
Type12ptMedium for other tabs, semibold for the selected one; mono numbers
Selected fill22%Accent fill with a 55% accent hairline
Other tabs6%Foreground wash; 10% on hover; 0.18s fade
Sidebar200ptFull-width rows, "New tab" row at the end
Tab colorsA 7pt dot at the start of the capsule replaces the full-width underline.
TitlebarWith bottom or sidebar tabs, the titlebar shows the focused tab's title, like a normal window.
Native tabs underneathThe bar still drives macOS tab groups, so restore, drag reorder and detach keep working.
