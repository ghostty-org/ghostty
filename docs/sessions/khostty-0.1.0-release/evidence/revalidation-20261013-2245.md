## New finding: dismissal comment could not be added post-hoc

The GitHub REST API for Dependabot alerts PATCH only accepts `dismissed_comment` with a
max length of 280 characters, AND only during the initial dismiss. After the alert is
in `state=dismissed`, subsequent PATCH calls with `dismissed_comment` return 422
("data matches no possible input" / "Only 280 characters are allowed" — both errors
observed across multiple attempts). The rationale is preserved in
`docs/sessions/khostty-0.1.0-release/evidence/validation-round6-20261012.txt` and
referenced from the SESSION-CLOSE-20261013.md. No further action needed.
