tests. The 207-vs-45 delta is not a regression — it reflects a rewrite
of the Go test harness to use `go test` directly (cleaner, smaller
suite, more focused on the cgo FFI surface). The Go package itself
exports the same FFI surface; the test count is just a different
counting granularity.
